Sensitive Health Data
ข้อมูลโรคประจำตัว ใบรับรองแพทย์ ประวัติการผ่าตัด การแพ้อาหาร/แพ้ยา น้ำหนัก มวลกล้ามเนื้อ และเปอร์เซ็นต์ไขมัน ถือเป็นข้อมูลสุขภาพที่ควรจำกัดการเข้าถึง ใช้เฉพาะเพื่อการดูแลสุขภาพ การวางแผนการฝึก และการติดตามสมรรถภาพของหน่วยเท่านั้น

1. กำหนดสิทธิ์การเข้าถึง

User เห็นเฉพาะข้อมูลของตนเอง ส่วน Admin เห็นภาพรวมและรายบุคคลตามหน้าที่ที่ได้รับมอบหมาย

2. จำกัดเอกสารแพทย์

ใบรับรองแพทย์และใบผ่าตัดให้เข้าถึงได้เฉพาะ Admin หรือผู้บังคับบัญชาที่ได้รับอนุญาต

3. บันทึกประวัติการแก้ไข

ทุกครั้งที่มีการแก้ไขข้อมูล ระบบควรบันทึกชื่อผู้แก้ไข วัน เวลา และรายการที่ถูกเปลี่ยนแปลง

4. การยืนยันตัวตน

กำหนดรหัสผ่านที่ปลอดภัย และควรเพิ่มการยืนยันตัวตน 2 ชั้นสำหรับ Admin

5. การเก็บไฟล์แนบ

รูปภาพ วิดีโอ และเอกสารแพทย์ควรเก็บในพื้นที่ปลอดภัย ไม่เปิดเป็นลิงก์สาธารณะ

6. การสำรองข้อมูล

สำรองข้อมูลตามรอบ เช่น รายวันหรือรายสัปดาห์ เพื่อป้องกันข้อมูลสูญหาย

7. การนำข้อมูลไปใช้

ใช้ข้อมูลเพื่อการฝึกและดูแลสุขภาพเท่านั้น ไม่ควรนำไปเผยแพร่โดยไม่จำเป็น

8. การลบหรือย้ายกำลังพล

เมื่อกำลังพลย้ายหน่วยหรือพ้นสภาพ ควรกำหนดขั้นตอนเก็บถาวร ลบ หรือระงับบัญชีอย่างชัดเจน
